## 说话人分离参数（2026-09-12 起，已固化进 w217/qwen3-asr:spk-params = latest）

- 请求级（优先）：/v1/audio/transcriptions form 字段或 /v1/asr query 参数
  - num_speakers：1-15，强制说话人数（CAM++ oracle_num）；越界 422
  - speaker_merge_thr：0-1，合并阈值（默认 0.78）
- 实例级默认（环境变量，外置）：SPEAKER_NUM_SPEAKERS、SPEAKER_MERGE_THR
  - 在 docker run -e 上配置即可改默认行为，请求不带参数时回落到它
  - 例：docker run -e SPEAKER_NUM_SPEAKERS=8 ...（多人群像素材常驻 8 人）
  - 不设则 SPEAKER_NUM_SPEAKERS 为空=CAM++ 自动估计，SPEAKER_MERGE_THR=0.78

## 声纹 embedding 端点（2026-10-04 起，已固化进 w217/qwen3-asr:spk-params = latest）

- POST /v1/audio/embeddings — ERes2NetV2 / CAM++ 双路声纹向量（192 维 L2 归一）
  - form：file 或 audio_address；models=eres2net/campplus/both（默认 both）
  - segments=JSON [{"start":0,"end":5},...] 显式切段；或 diarize=true 用 CAM++ 分离自动切段（可配 num_speakers）
  - 不给 segments/diarize 则整段一条；多模型时响应带 embeddings_by_model
- POST /v1/audio/speaker-compare — 两段音频双路余弦 + 等权融合，threshold 给定时输出 same_speaker
- 鉴权同转写：Authorization: Bearer devideo2026asrkey
- 权重：ERes2NetV2 ckpt 已烘焙到容器内
  /root/.cache/modelscope/hub/models/iic/speech_eres2netv2_sv_zh-cn_16k-common/pretrained_eres2netv2.ckpt
  （71,768,231 B，md5 b0e3fdeb 前缀），无需 -e；如需换权重可用
  SPEAKER_ERES2NETV2_CKPT（显式文件）或 SPEAKER_ERES2NETV2_MODEL（id/目录）覆盖。
  权重原件在 /nas2/models/eres2netv2/。
